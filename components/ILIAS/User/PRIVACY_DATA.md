# User Privacy

> **Disclaimer: This documentation does not guarantee completeness or accuracy. Please report any
> missing or incorrect information via the [ILIAS issue tracker](https://mantis.ilias.de) or a
> [Pull Request](../../../docs/development/contributing.md#pull-request-to-the-repositories).**

## Integrated components

- [Mail](../Mail/PRIVACY.md): receives the postal address to send the profile data of an account by mail, e.g. to a new account

## Data being stored

- The postal address is stored to keep it as part of the profile of the user account.

## Data being presented

- If the person has published it in their profile, the postal address is presented on the public profile of the person to persons who can see the public profile, to show the profile the person has published.
- The postal address is presented in the profile form to the person the account belongs to and persons who can edit user accounts, to edit it.

## Data being deleted

_This section has not been documented here yet. This does not mean that no personal data is processed._

## Data being exported

- If the person has published it in their profile, persons who can see the public profile can export the postal address as vCard from the public profile of the person, to add the person to an address book.
